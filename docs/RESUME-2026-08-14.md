## Read this first: why nothing was deployed

The work spans three targets that must land **together**:

| Target | Carries | How it deploys |
|---|---|---|
| **Bridge** | power fix, Golden Profile, jitter diagnosis + ladder, live-acting sentry | **New image + reflash only** |
| **Control plane** | new menu, Config column, diagnosis panel | `deploy.sh` to Lightsail |
| **Presenter app** | adopts fleet-published tuning (1.1.6) | rebuild + install |

Deploying the **control plane alone would give you buttons the bridge cannot execute** —
`golden-*` and `jitter-*` would queue and the device agent would refuse them, which looks
exactly like the silent-nothing failure the gate test exists to prevent. So it waits.

### Why the bridge needs a whole image

The signed-override path can only replace scripts launched through `bridge-run.sh`:

```
bridge-feeder-audio.sh   bridge-feeder-net.sh   bridge-return-audio.sh   bridge-uvcd.sh
```

**None of this work is in those four files.** It is in `bridge-web.py`, `jitter-sentry.sh`,
`bridge-agent.py`, the `bridge` CLI, and two new scripts — all baked-in only.

Card surgery is not available either: **port 22 is closed on the bridge and Tailscale SSH was
never enabled**. Confirmed, not assumed. So: image.
